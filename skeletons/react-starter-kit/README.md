# Hypervel + React Starter Kit

> **Work in progress.** This starter kit is under development and is not yet ready to use.

## Introduction

A starting point for building Hypervel applications with a React frontend using [Inertia](https://inertiajs.com).

## Contributing

This repository is a read-only subtree split. Development takes place in [`hypervel/components`](https://github.com/hypervel/components/tree/0.4/skeletons/react-starter-kit). Please submit issues and pull requests there.
