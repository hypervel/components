# Generated configuration stubs

Do not edit the PHP files in this directory by hand. They are generated from the framework defaults in [`../config/`](../config/) and are used by `php artisan config:publish` when framework config merging is enabled.

In the [components monorepo](https://github.com/hypervel/components), edit the defaults in `src/foundation/config/` or the publishing rules in `bin/sync-skeleton-config/rules.php`, then run:

```sh
composer sync:skeleton-config
composer check:skeleton-config
```

Review and commit the generated changes with the source changes. See [`bin/sync-skeleton-config/README.md`](https://github.com/hypervel/components/blob/0.4/bin/sync-skeleton-config/README.md) for instructions and rule syntax.
